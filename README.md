# SIRENS.AI — лендинг

Next.js (App Router) + TypeScript. Вёрстка перенесена один в один из макета
Claude Design **«Sirens Landing v4»**:
https://claude.ai/design/p/8df67d20-84a2-4492-ad24-b6da5538a4cd?file=Sirens+Landing+v4.dc.html

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # прод-сборка
npm start
```

## Первый экран

Вместо статичной картинки — ролик с маячком, отмотка которого привязана к
скроллу. Сцена высотой 360vh: пока листаем, заголовок уходит, камера наезжает на
лампу, а на последнем кадре вокруг неё проявляются три карточки направлений с
выносками-линиями, как на чертеже.

Поверх кадра идёт ореол от лампы: два радиальных градиента на `mix-blend-mode:
screen`. Он ездит за лампой — координаты и радиус берутся из таблицы `LAMP_TRACK`
в `HeroScroll.tsx`, снятой покадрово с самого ролика (камера не просто наезжает,
в середине лампа уходит влево и возвращается). Ведём ореол не по позиции скролла,
а по `requestVideoFrameCallback`: перемотка асинхронная, и по скроллу свет
обгонял бы картинку. Пока страницу не тронули, ореол пульсирует; на первом же
скролле пульсация выключается, а к финалу яркость убавляется, чтобы лампа не
засвечивала карточки.

Карточки шириной `min(400px, 28vw)`, высота от содержимого; слева — стеклянная
картинка направления (`card-*-glass.png`), на ховере она слегка увеличивается.
Выноски рисуются в `HeroScroll.tsx` в SVG по фактическим координатам карточек.
Целятся в центр сцены: ролик вписан по `object-fit: cover` без сдвига, поэтому
лампа финального кадра приходится ровно на середину экрана. Габарит плафона
задан константами `lampA` и `lampB` в координатах ролика 1600×900.

На экранах уже 900px и при `prefers-reduced-motion` привязка к скроллу
отключается: видео крутится в цикле фоном, карточки идут обычным блоком ниже.

| Файл | Что это |
| --- | --- |
| `hero-beacon.mp4` | 1600×900, без звука, ключевой кадр через один — чтобы перемотка не дёргалась |
| `hero-beacon-loop.mp4` | 1280×720, лёгкая версия для зациклённого режима |
| `hero-beacon-poster.jpg` | первый кадр, показывается до загрузки видео |

Пересобрать из исходника `docs/source/video/hero-beacon-source.mp4` (5,5 МБ, 1920×1080, 8 с):

```bash
ffmpeg -i docs/source/video/hero-beacon-source.mp4 -an -vf scale=1600:900 -c:v libx264 \
  -preset veryslow -crf 23 -g 2 -keyint_min 2 -sc_threshold 0 -pix_fmt yuv420p \
  -movflags +faststart public/assets/hero-beacon.mp4
```

Плотные ключевые кадры обязательны: с обычным GOP перемотка по скроллу
подтормаживает. CRF 23 на этом материале от исходника не отличается.

Фон «Контактов» — тот же кадр, что был на `industrial-night.png`, только маяк
мигает. Ролик просто зациклен, перемотки нет, поэтому плотные ключевые кадры не
нужны:

```bash
ffmpeg -i docs/source/video/contacts-beacon-source.mp4 -an -vf scale=1600:900 \
  -c:v libx264 -preset veryslow -crf 24 -pix_fmt yuv420p -movflags +faststart \
  public/assets/contacts-beacon.mp4
ffmpeg -i public/assets/contacts-beacon.mp4 -vframes 1 -q:v 4 \
  public/assets/contacts-beacon-poster.jpg
```

## Выноски к лампе

Первый экран и блок «Мы слышим риск раньше» построены одинаково: стеклянные
карточки вокруг лампы и ломаные выноски к ней — стойка от грани карточки, полка
по горизонтали, скос под 45° и красная точка на контуре лампы. Геометрия одна на
оба блока, в [lib/leaders.ts](lib/leaders.ts); каждый блок задаёт только центр и
полуоси лампы.

- На первом экране лампа — центр сцены, полуоси в координатах ролика 1600×900.
- В «Философии» центр берётся из `siren-cutout.png`: плафон приходится на середину
  по ширине и на 33% высоты. Константы — в `LAMP` в `Philosophy.tsx`.

Карточки «Философии» стоят зеркально (верхняя пара у краёв, нижняя со сдвигом
внутрь) и проявляются, когда блок входит в экран, со сдвигом по очереди. Вместо
номера в каждой — маленькая линейная сирена со своим атрибутом (`PrincipleSiren`
в `Philosophy.tsx`).

Нижние 20% сирены уходят за край секции, как в макете. Чтобы срез не читался
жёсткой линией, основание гаснет в черноту плашкой `.siren::after` (шире бокса —
накрывает и ореол от `drop-shadow`), а красное пятно под ней — маской. Маска на
самой лампе не годится: режет ореол по боксу вертикальными краями. Следующая
секция («Диагностика») берёт сверху `--section-y` + `--space-8`, потому что у
«Философии» нижнего отступа нет.

На экранах уже 900px выноски скрываются, сирена уходит наверх без обрезки и
плашки, карточки идут сеткой под ней.

## Шапка

Закреплена над всей страницей (`components/Header.tsx`). Наверху висит свободно
с отступом `--header-pad` (48px), как в макете первого экрана; после прокрутки
на 24px прижимается, получает тёмную стеклянную подложку и линию снизу. Первый
экран оставляет под неё место через `--nav-h` + `--header-pad`, якоря секций —
через `scroll-margin-top`. Переходы по якорям плавные (`scroll-behavior: smooth`,
выключается при `prefers-reduced-motion`).

На ≤640px ссылки и кнопка уходят под бургер в выпадающую панель; закрывается по
клику на ссылку, по Esc и при развороте экрана.

## «Почему это актуально»

Bento-сетка из макета: 6 колонок, `grid-auto-flow: dense`, размер каждой ячейки
задан в `lib/content.ts` полями `col`/`row` и приходит модификаторами
`trigger--w{2|3|6}` / `trigger--h{1|2}`. От макета отличается сознательно:
без радиального пятна и без слота под 3D-иконку, ховер — только красная обводка.

Вместо номера в углу — сирена из `components/SirenIcon.tsx`: девять разных
композиций (бюст, сидящая, плывущая, ныряющая, хвост из воды, кольцо,
птица-сирена, портрет, маяк), у каждой атрибут по смыслу карточки (пустой лист,
весы, рог, знак опасности, монеты, силуэт-вакансия, лупа, замок, второй маяк).
Правило чистоты: линии не пересекаются посередине — только начинаются или
заканчиваются на другой линии; пряди стартуют с окружности головы. Проверяется
геометрически, а не на глаз: см. заголовок файла.

## Диагностика: арты шагов

У каждого из пяти шагов — своя картинка-вырезка `diagnostics-step-0N-cutout.png`
поверх карточки; на ховере слегка увеличивается. Под сеткой — красная подсветка
через `::after` на `mix-blend-mode: screen`. В макете этого нет.

## Типографика и отступы

Все кегли, межстрочные, разрядки и отступы на сайте берутся из токенов в `:root`
([app/globals.css](app/globals.css)). Число в пикселях в правиле — ошибка:
если нужного размера нет в шкале, добавляем токен, а не пишем `17px`.

### Кегли — 8 ступеней

| Токен | Значение | Роль | Где |
| --- | --- | --- | --- |
| `--text-xs` | 12px | ярлык: uppercase, 600, разрядка `+0.08em`; eyebrow над заголовком секции — исключение: с большой буквы, без разрядки | eyebrow, подписи контактов и полей, номера «01», теги |
| `--text-sm` | 14px | мелкий текст | пояснения в карточках, примечания, консент, футер, роль в команде |
| `--text-base` | 16px | основной текст | навигация, пункты услуг и цены, био, кнопка `cta--md` |
| `--text-md` | 18px | лид и заголовок компактной карточки | `.lede`, поля формы, значения контактов, `cta--lg`, заголовки карточек направлений и шагов |
| `--text-lg` | 22px | заголовок блока | логотип, названия групп услуг, триггеры «Почему», заголовок формы |
| `--text-xl` | 36px | имя и крупное число | имена в команде, цифры в статистике |
| `--text-h1` | `clamp(36px, 3.8vw, 56px)` | заголовок секции | `.section-title` |
| `--text-display` | `clamp(40px, 6.4vw, 96px)` | дисплей | первый экран, «Философия», призрачная цифра в триггере |

Шрифты: всё, что `lg` и крупнее, плюс номера и цифры — Space Grotesk; остальное —
Manrope. Заголовки `h1`/`display` идут с `--tracking-title` (−0.03em) /
`--tracking-display` (−0.04em), заголовки блоков — с `--tracking-heading`
(−0.02em), ярлыки — с `--tracking-label` (+0.08em).

Межстрочные — два токена: `--leading-tight` (1.05) для всего от `xl` и выше,
`--leading-normal` (1.6) для текста, `--leading-snug` (1.25) для заголовков
карточек в одну-две строки.

На ≤640px `--text-xl` → 30px, `--text-lg` → 20px, `--text-display` →
`clamp(34px, 10vw, 44px)` (слово «БЕЗОПАСНОСТИ» должно влезать в 342px одной
строкой); `h1` ужимается сам через `clamp`.

### Отступы — шаг 4px

| Токен | px | Токен | px |
| --- | --- | --- | --- |
| `--space-1` | 4 | `--space-6` | 32 |
| `--space-2` | 8 | `--space-7` | 48 |
| `--space-3` | 12 | `--space-8` | 64 |
| `--space-4` | 16 | `--space-9` | 96 |
| `--space-5` | 24 | `--space-10` | 128 |

Поверх шкалы — семантические токены, ими и пользуемся в правилах секций:

| Токен | Десктоп | ≤1180 | ≤900 | ≤640 | Что это |
| --- | --- | --- | --- | --- | --- |
| `--pad-x` | 64 | 48 | 24 | 24 | горизонтальные поля страницы |
| `--section-y` | 128 | 128 | 96 | 64 | вертикальный отступ секции |
| `--section-gap` | 64 | 64 | 48 | 48 | шапка секции → её содержимое |
| `--head-gap` | 24 | | | | eyebrow → заголовок → лид → кнопка |
| `--col-gap` | 64 | 48 | 48 | 48 | между колонками двухколоночной секции |
| `--grid-gap` | 16 | | | | между карточками в сетке |
| `--card-pad` | 24 | | | | внутренний отступ обычной карточки |
| `--card-pad-lg` | 48 | 48 | 32 | 32 | карточка команды и форма заявки |
| `--radius` / `--radius-sm` | 16 / 12 | | | | скругления карточек / кнопок и пилюль |

Внутри карточек: между ярлыком и заголовком — `--space-2` (8), между
заголовком и текстом — `--space-3` (12), между тегами и текстом — `--space-4` (16).

### Как этим пользоваться

- Новый элемент — сначала определить его роль (ярлык? текст? заголовок блока?)
  и взять соответствующий токен. Не подбирать «на глаз».
- Общие роли уже собраны в групповые правила в начале `globals.css`:
  ярлык (`.eyebrow, .contact__label, …`), номер (`.beacon-card__n, …`),
  заголовок блока (`.trigger__text, .group__title, …`). Новый элемент той же
  роли добавляется в селектор, а не получает копию свойств.
- Адаптив меняет только семантические токены в `:root` внутри медиа-запросов,
  а не отступы конкретных секций.

## Подсветка тёмных секций

Середина сайта — сплошной чёрный. Секции «Почему», «Услуги», «Диагностика» и
«Команда» получают мягкие красные пятна через `::before` и `::after` на
`mix-blend-mode: screen`: так подсвечивается и фон, и непрозрачные карточки, а
белый текст не мутится. Пятна медленно дышат с разными периодами и сдвигами, у
«Услуг» их два — левая половина там самая пустая. Всё выключается при
`prefers-reduced-motion`.

Крутить яркость — в альфе градиентов в `app/globals.css`, блок «фоновая подсветка
тёмных секций».

## Прелоадер и появление при скролле

**Прелоадер** — [components/Preloader.tsx](components/Preloader.tsx). Пульсирующий
маячок, слово SIRENS.AI побуквенно из-под маски, счётчик 000→100 и волосяная
красная линия. Прогресс честный: ждёт шрифты и событие `load`, но не меньше
1,6 с, чтобы проявилось слово, и не больше 3,5 с. На выходе маячок вспыхивает,
экран уезжает вверх шторкой, из-под неё поднимаются заголовок, кнопка и шапка.

**Появление при скролле** — [components/Reveal.tsx](components/Reveal.tsx). Ярлыки,
лиды и карточки поднимаются с проявлением, заголовки секций раскрываются маской
снизу вверх. Что входит в экран одновременно, идёт лесенкой с шагом 70 мс, не
больше шести ступеней. Каждый элемент анимируется один раз. Список целей
продублирован в CSS, блок «Появление при скролле» в `app/globals.css`, — менять
оба места вместе.

Как это держится вместе. Ранний скрипт в [app/layout.tsx](app/layout.tsx) до
первой отрисовки ставит на `<html>` классы `is-preloading` и `reveal-ready`. После
прелоадера появляется `is-loaded` и событие `sirens:loaded` — от них стартуют вход
первого экрана и наблюдение за скроллом.

Страховки:

- без JavaScript классов нет — прелоадер скрыт, весь текст виден сразу;
- если React не ожил за 6 секунд, скрипт снимает прелоадер и показывает текст;
- при `prefers-reduced-motion` появления нет, прелоадер коротко гаснет без анимации;
- анимации идут через keyframes с `backwards`, а не через transition: иначе
  конфликтовали бы с наклоном стеклянных карточек из `GlassEffects`.

Кривые и длительности — токены `--ease-out`, `--ease-in-out`, `--dur-reveal` в `:root`.

## Что требует решения перед показом заказчику

**Фото основательниц** не заданы и в макете: слоты в `components/Team.tsx` пустые,
в выгрузке из Claude Design фотографий нет. Положить файлы в `public/assets/team/`
и указать путь в поле `photo`.

**Контакты и цены** — черновые, как в макете. Телефоны и Telegram оставлены
плейсхолдерами намеренно, цены взяты из брифа. Сверить с заказчиком.

**Форма заявки** пока только меняет надпись на кнопке. Куда отправлять заявку
(почта, CRM, Telegram) — не решено; под это заведём Server Action.
